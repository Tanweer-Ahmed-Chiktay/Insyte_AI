# Gmail Pub/Sub Worker Setup & Troubleshooting Guide

## Overview
This guide helps you set up and troubleshoot the Gmail Pub/Sub worker that processes Gmail notifications in real-time.

## Key Issues Fixed

### 1. OAuth Token Refresh Problems
- **Problem**: `GaxiosError: invalid_request` with status 400
- **Root Causes**:
  - Invalid or expired refresh tokens
  - Incorrect OAuth client configuration
  - Missing or malformed tokens in database
  - Network issues during token refresh

### 2. Database Schema Mismatch
- **Problem**: Code expects Prisma models but uses raw SQL schema
- **Solution**: Aligned Prisma schema with your database structure

### 3. Error Handling Improvements
- Added comprehensive try-catch blocks
- Better logging for OAuth errors
- Graceful degradation when services fail

### 4. Pub/Sub Configuration

#### Create Topic and Subscription
```bash
# Create topic
gcloud pubsub topics create gmail-notifications

# Create push subscription
gcloud pubsub subscriptions create gmail-worker-subscription \
    --topic=gmail-notifications \
    --push-endpoint=https://gmail-worker-[hash]-uc.a.run.app/pubsub \
    --ack-deadline=600
```

### 5. Gmail Push Notifications Setup

#### Set up Gmail Watch
You'll need to call the Gmail API to set up push notifications:

```javascript

await gmail.users.watch({
  userId: 'me',
  requestBody: {
    topicName: 'projects/insyte-467414/topics/gmail-notifications',
    labelIds: ['INBOX', 'UNREAD']
  }
});
```

## Deployment

### 1. Build and Deploy
```bash
# Build Docker image
docker build -t gcr.io/insyte-467414/gmail-worker:latest .

# Push to Container Registry
docker push gcr.io/insyte-467414/gmail-worker:latest

# Deploy to Cloud Run
gcloud run deploy gmail-worker \
    --image gcr.io/insyte-467414/gmail-worker:latest \
    --region us-central1 \
    --platform managed \
    --allow-unauthenticated \
    --memory 2Gi \
    --cpu 2 \
    --timeout 3600 \
    --concurrency 80 \
    --max-instances 10 \
    --service-account gmail-worker-sa@insyte-467414.iam.gserviceaccount.com
```

```bash

    --push-endpoint=https://gmail-worker-[your-hash]-uc.a.run.app/pubsub
```

## Troubleshooting

### Common OAuth Errors

#### 1. `invalid_request` Error
**Symptoms**: 400 Bad Request when refreshing tokens
**Causes & Solutions**:
- **Invalid refresh token**: User needs to re-authenticate
- **Expired refresh token**: Check token expiration in database
- **Malformed token**: Verify encryption/decryption is working
- **Wrong OAuth client**: Verify GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET

#### 2. `invalid_grant` Error
**Symptoms**: 400 Bad Request with "invalid_grant"
**Causes & Solutions**:
- **Expired refresh token**: User must re-authenticate via OAuth flow
- **Token used too many times**: Refresh tokens have usage limits
- **Clock skew**: Ensure server time is synchronized
